# QA Automation - Simple Storage Assignment

This repository contains the QA automation project for the Simple Storage backend assignment.

## Project Structure

- `test_api.py` - Main Pytest automation script for API tests.
- `requirements.txt` - Python dependencies.
- `sample.txt` - Sample file for testing upload/download.
- `assets/` - Any supporting files for tests.
- `report.html` - Generated HTML report after test execution.
